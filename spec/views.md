## Implementation notes

- One model chain per window: `DirectoryList` → `FilterListModel` (hidden files) → `SortListModel` → `MultiSelection`. Positions in `activate` refer to the sorted model, so look items up in the selection. Get an item's `gio::File` from the `standard::file` attribute (`dnd::file_of`).
- The sorter is a `MultiSorter`: `dirs_first`, then the `ColumnView`'s sorter. This is how the column headers also sort the icon view.
- Grid labels are `gtk::Inscription`, not `gtk::Label`. A word-wrapped Label requests the width of its longest word and widens every column. `window::word_wrapped_lines` measures a Pango layout (`WrapMode::Word`, cell width) and sets min/nat lines to the lines needed. It stops at the first overflowing line, so that line is the last one and gets ellipsized. The inscription is top-aligned, so its allocation is exactly that many lines.
- Spacing values come from Nautilus 50: `src/resources/style.css`, `src/nautilus-grid-cell.c` (`EMBLEMS_BOX_WIDTH 18`, `VERTICAL_PADDING 6`) and `src/nautilus-enums.h`.
