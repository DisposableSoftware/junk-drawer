## Implementation notes

- One `CssProvider` at `STYLE_PROVIDER_PRIORITY_USER`. It concatenates, in order: `data/themes/<flavor>.css` (`@define-color` palette), the generated `@accent` and `@bg`, `data/style.css`, and the user's `style.css`.
- Named colours resolve across providers, highest priority first: a name defined only in `~/.config/gtk-4.0/gtk.css` is usable in Junk Drawer's CSS (checked on GTK 4.22). `LOOK-15` relies on this. libadwaita-style themes (adw-gtk3, Stylix) define `window_bg_color`, `window_fg_color` and `accent_bg_color`; GTK's built-in theme defines only `theme_bg_color`, `theme_fg_color` and `theme_selected_bg_color`, so the first set falls back to the second.
- The palette hex values come from https://catppuccin.com/palette. The theme files list the 26 colours in Catppuccin's order.
